
  # Rondi trasporti AI

  This is a code bundle for Rondi trasporti AI. The original project is available at https://www.figma.com/design/2sYL4mNRaBVgA9OXqEvsJw/Rondi-trasporti-AI.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the Nuxt development server.

  Run `npm run build` to build the Nuxt app for production.

  Run `npm run preview` to preview the production build locally.
